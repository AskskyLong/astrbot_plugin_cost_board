# astrbot_plugin_cost_board

把 AstrBot `provider_stats` 里的 token 换算成**人民币**，按天 / 模型 / 会话拆账。

模型后台只给你一个月度总额，看不出是哪个群、哪个会话在烧钱。这个插件补上这一段。

## 它解决什么问题

- 只看得到「这个月花了多少钱」，看不到「哪个群花得最多」
- 想知道缓存命中率，但 `provider_stats` 里那几个字段容易算错（下面有坑）
- 想比较换模型能省多少，但没有统一的人民币口径

## 命令

| 命令 | 作用 |
|---|---|
| `/费用` | 今日花费、调用次数、按模型占比、最烧钱的会话、缓存命中率 |
| `/费用 天` | 逐日花费，看趋势 |

默认**仅管理员可用**。

## 两条口径，先说清楚（这两条我踩过）

**1. `provider_stats` 一行 = 一次 agent run，不是一次 API 请求。**
一个 run 里可能有多轮工具循环。`token_input_cached` 是这个 run 的**累计命中量**，
不是单次请求的值。拿它除以单次输入 tokens 去算命中率，会算出超过 100% 的数。

**2. 省 token ≠ 省钱。**
缓存命中段的输入单价只有未命中的 2%（DeepSeek 为例：0.04 元 vs 2.0 元 / 百万 tokens）。
省下来的如果是命中段，几乎不省钱。真正省钱的是：少调用、换便宜的模型、砍掉没用的工具块。

## 隐私与安全

- 数据库用 sqlite `mode=ro` **只读**打开，不写、不改
- **不联网**，不上报任何数据
- 无第三方依赖，只用到标准库
- 不修改 AstrBot 配置

## 配置

价格表可改（`prices`）。没配到的模型按 **0 元计并明确标注「未配价」**，不假装算得准。

如果你用的模型不在默认价格表里，把你的实际单价发到 issue，我补进去。

## 安装

在 AstrBot 插件市场搜索 `cost_board` 安装，或：

```bash
cd AstrBot/data/plugins
git clone <本仓库地址> astrbot_plugin_cost_board
```

然后重启 AstrBot。

## 验收

1. 在本机发 `/费用` —— 出现今天的金额和调用次数，就算通了
2. 再发 `/费用 天` —— 应能看到逐日柱状条
3. 若显示「未配价」，说明你的模型不在默认价格表里

## 兼容性

- AstrBot `>= 4.25.0`
- Python 3.10+
